# USSD Workflows & Session Trees

## Shortcode: `*990#`

## Multilingual Support
1. English
2. Amharic (አማርኛ)
3. Hamer (Hamer-Banna phonetic transliteration)

## Core Menus
- **Main Menu**:
  1. Sell Produce / Record Supply
  2. Check Market Prices
  3. View Recent Sales & Balance
  4. Change Language / Settings
- **Sell Produce Sub-menu**:
  1. Honey (White / Amber / Forest)
  2. Coffee / Spices
  3. Handicrafts
  4. Enter quantity (kg / items)
  5. Select pickup hub (Turmi / Jinka / Dimeka)
