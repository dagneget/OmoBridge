# Gateway Sandbox Configuration

This directory contains configuration templates and mock endpoints for external telecom aggregators (e.g., Ethio Telecom, Safaricom, Africa's Talking) providing:
- USSD channel callback handling
- Inbound and Outbound SMS
- IVR / Voice menu gateways
